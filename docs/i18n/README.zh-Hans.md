## 研究方向

把行为资料与有明确校准、时间同步和实验背景的多巴胺测量相结合，是否能帮助研究者更好理解运动？这是待验证的问题。

DA-OS Matrix 指包含背景信息的数据和模型，不是每个动作对应唯一多巴胺剂量的万能表。先使用实验室有权共享的现有数据，再进行同步、质量检查、基准分析和独立复现。新的动物或人体研究必须由合格机构在所需伦理批准下进行。

FSCV 和 GRAB 传感器是候选的既有研究方法；传感器性质、校准与真实时间分辨率必须记录。数据格式会考虑采用 NWB。具体依据与限制见[白皮书](../WHITEPAPER.md)。

## 验证目标

- 由专家明确一个范围小、可被证伪的研究假设。
- 合法取得的数据能被重复加载、同步与检查。
- 在独立个体和时段上评估模型，报告不确定性与失败。
- 由其他团队复现，并实测跨实验室迁移能力。
- 闭环干预、细胞再生及治疗属于另外的长期研究，不能由对照表自动推出。

当前只有提案、白皮书、翻译和参与说明，尚未提供设备、数据库、模型、临床研究或治疗结果。没有证实根治、精确剂量或从动物直接转用于人类。
