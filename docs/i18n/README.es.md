## La propuesta

Sincronizar observaciones de comportamiento y señales de dopamina, conservando calibración, contexto y limitaciones. La **DA-OS Matrix** sería un conjunto de datos y modelos dependientes del contexto, no una tabla universal que asigna una dosis a cada movimiento.

Empezar con datos existentes que laboratorios cualificados puedan compartir legalmente. Después: alineación, control de calidad, análisis reproducible y validación independiente. Cualquier nueva investigación animal o humana requeriría instituciones cualificadas y las aprobaciones éticas correspondientes.

FSCV y sensores GRAB son métodos de investigación existentes que podrían evaluarse. Deben documentarse las propiedades y la resolución real de cada sensor; se consideraría NWB para interoperabilidad. Los fundamentos están en el [documento completo](../WHITEPAPER.md).

## Qué demostrar primero

- Una pregunta concreta y una hipótesis que expertos puedan refutar.
- Carga y sincronización reproducibles de un conjunto de datos autorizado.
- Evaluación en animales y sesiones no usados para entrenar, con incertidumbre y análisis de fallos.
- Reproducción por otro equipo y pruebas de transferencia entre laboratorios.

Hoy solo hay documentación: no se ofrece dispositivo, base de datos, modelo entrenado ni resultado clínico. No se ha demostrado una cura, una dosificación exacta ni transferencia directa a humanos. La regeneración y las intervenciones de circuito cerrado necesitarían programas separados.
