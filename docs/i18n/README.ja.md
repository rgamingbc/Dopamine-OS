## 研究構想

行動記録とドーパミン信号を同期し、校正、実験状況、測定限界を残します。**DA-OS Matrix** は状況に依存するデータとモデルであり、すべての動作に唯一の投与量を割り当てる万能表ではありません。

まず、適格な研究機関が利用許可を得て共有できる既存データを用います。その後、同期、品質確認、再現可能な解析、独立した検証を行う構想です。新たな動物・人の研究には、適切な機関と必要な倫理承認が必要です。

FSCVとGRABセンサーは検討対象となる既存の研究手法です。センサーの特性と実際の時間分解能を記録し、相互運用性にはNWBの利用を検討します。根拠と限界は[ホワイトペーパー](../WHITEPAPER.md)に記載しています。

## 最初に検証すること

- 専門家が絞り込んだ、反証可能な研究仮説。
- 利用許可のあるデータの再現可能な読み込みと同期。
- 学習に含めていない個体・セッションでの評価、不確実性と失敗の分析。
- 別チームによる再現と、研究機関をまたぐ検証。

現在提供しているのは文書のみです。装置、データベース、学習済みモデル、臨床成果はありません。治癒、正確な投与量、動物から人への直接的な適用は実証されていません。細胞再生や閉ループ介入には別の研究計画が必要です。

## 事業への意欲と協力募集

最初は研究に役立つ基盤を作ります。検証と採用が進めば、研究ソフトウェア支援、データ統合、共同研究を検討できます。「1兆ドル規模の夢」は意欲の表現であり、算出済み市場規模、評価額、利益の保証ではありません。人間の能力拡張やロボットへの応用は、未検証の遠い可能性です。

科学者、臨床専門家、研究機関、AI・データ技術者、投資家、慈善支援者、翻訳者を求めています。最初の資源は専門家評価、適法なデータ取得、開発時間、独立検証に充てる構想で、予算と節目は今後合意します。
